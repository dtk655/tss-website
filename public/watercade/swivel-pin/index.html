90° Swivel Pin

Every WATERCADE™ has a swivel pin built in. Each connection turns up to 90°, so one barrier line can run straight, wrap a corner, or close off an entire work zone.

  • No Corner Pieces Needed

    Every turn happens at the pin, with no special corner units.

  • Built Into Every Barrier

    Each unit arrives with its pin, ready to link.

  • Turns Up to 90°

    Follows curves, corners, and the shape of your work zone.

  • Full Perimeters

    Close off excavations, equipment, or event areas.

  • Link Empty, Fill in Place

    Set and connect barriers empty, then fill them on site.

  • Fence Ready

    Swap the pin for a fence panel post when you need added height.
